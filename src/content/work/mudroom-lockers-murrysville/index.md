The back hallway was where the coats and boots ended up, so we made it the place they belong. A bench with a lift-up seat for boots, four lockers with hooks and a shelf each, and a shiplap wall behind it all so the hooks land on solid wood. Everything is painted a warm white that wipes clean, and the base is set a half inch off the tile so a wet mop fits under it.
